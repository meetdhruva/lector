# Third-party assets

| Path | Project | License |
|---|---|---|
| `fonts/jetbrains-mono/` | [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) 2.304 (Regular, Bold, Italic, Bold Italic) | SIL Open Font License 1.1 (`fonts/jetbrains-mono/OFL.txt`) |
| `fonts/inter/` | [Inter](https://github.com/rsms/inter) 4.1 (Regular, Medium, SemiBold) | SIL Open Font License 1.1 (`fonts/inter/OFL.txt`) |

The fonts are embedded into the binary by `lector-ui` (`assets.rs`) so the UI
looks the same on every platform. File and UI icons live in
`crates/lector-icons/assets/` (see `crates/lector-icons/THIRD_PARTY.md`).
